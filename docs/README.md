# Docs

The thinking behind PAUSE, in the order it happened.

- `rough-idea.md` is the first version of the idea.
- `idea-honing.md` holds the questions and answers that shaped the requirements.
- `research/` holds the research notes on email parsing, privacy, AI tagging, hosting and similar apps.
- `design/detailed-design.md` is the full design.
- `implementation/plan.md` is the build plan.
- `summary.md` ties them together.
- `pdd.sop.md` is the process I followed to produce these documents.
- `mockups/` holds early visual explorations. The shipped app has moved on from them.

## What changed after the plan

These documents describe the first plan, from September 2026. The app has moved on, and that's on purpose. I kept the plan as it was so you can see where it started.

The ORM is Prisma, the database is Neon Postgres and the site runs on Vercel.

Reading Gmail is built but switched off. Google has to review any app that reads Gmail before real people can connect, so the demo comes first. Outlook was never built.

Comparable and secondhand suggestions were cut. They pushed you toward buying something else, which works against the point of a pause.

Post wait recommendations became Still want it, and text outfit ideas became a board where you build looks from your own closet.

Save for later became Undecided. Pauses end silently, with no reminder.

Adding an item only takes typed text. Reading links and screenshots wasn't reliable enough to keep.

The budget grew into Budget and goals, with an optional savings goal.

The pause screen asks the three reflection questions from the research, and Decisions sorts every item into On pause, Undecided, Let go or Bought.

The README covers the app as it works today.
