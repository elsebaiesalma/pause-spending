# Docs

The thinking behind PAUSE, in the order it happened.

- `rough-idea.md` is the first version of the idea.
- `idea-honing.md` holds the questions and answers that shaped the requirements.
- `research/` holds the research notes on email parsing, privacy, AI tagging, hosting and similar apps.
- `design/detailed-design.md` is the full design.
- `implementation/plan.md` is the build plan.
- `summary.md` ties them together.
- `pdd.sop.md` is the process I followed to produce these documents.
- `mockups/` and `superdesign/` hold early visual explorations. The shipped app has moved on from them.
